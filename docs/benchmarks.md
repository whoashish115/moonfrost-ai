# Benchmarks

Every number here was measured on an RTX 3050 with the same harness: the answer option
whose continuation the model finds most likely wins, with a length-normalised variant
taken alongside and the better of the two reported. 250 examples per benchmark for every
model. The tables are generated by `training/sync_benchmarks.py` straight from
`eval*.json`, so they cannot drift from the files they describe.

**The reference models were run through that same harness on the same examples.** Figures
copied from other model cards would compare harnesses as much as models, since prompt
wording and normalisation move these numbers several points.

## Reading it

**SmolLM2-360M wins most task families at half the total size.** It read about 2 trillion
tokens; Moonfrost read 6 billion. Roughly 330 times more text.

**Chance is the number to read first.** 44.4 on ARC-Easy is nearly twice chance on a
four-option question. 58.8 on BoolQ is eight and a half points above chance on a two-option
one, which is much less than it looks.

**±6 points is the noise floor.** At 250 examples the 95% interval on a single score is
about six points either way, and fifteen of the eighteen gaps between the three Moonfrost
checkpoints are under three. ARC-Easy is the only benchmark that moves: 54.8, 52.4, 44.4
across the base, the half-epoch tune and the 1.7-epoch tune. The cost of chat formatting on
a multiple-choice stem, and it grows with how long you tune.

**The five-shot prompt is worth up to 14 points.** The harness takes its in-context
examples from the rows just after the evaluation slice, so the number of examples also
decides the prompt. An earlier run of the instruct weights over 200 examples scored 44.5 on
BoolQ; the run over 250 scored 58.8. That is the whole argument for scoring every model
here rather than copying figures from other cards.

## Why it scores where it does

At 6B tokens for 777M parameters, Moonfrost is at about **8 tokens per parameter**.
Chinchilla's compute-optimal ratio is around 20. The reference models are at 15,000 and
5,500.

| Model | Parameters | Tokens | Tokens per parameter |
|---|---|---|---|
| Moonfrost | 777M | 6B | 8 |
| SmolLM2-135M | 135M | ~2T | ~15,000 |
| SmolLM2-360M | 362M | ~2T | ~5,500 |
| Chinchilla | 70B | 1.4T | 20 |
| Llama 3 8B | 8B | 15T | 1,875 |

The budget bought behaviour, not knowledge. The model chats, holds a thread, and knows
what it is; it does not know much.

## Behavioural findings

Separate from the benchmarks, 164 prompts were run through the model and judged on
whether the answer completed and held together. **148 passed.** The 16 failures were
almost all the same shape:

| Fails | Example |
|---|---|
| Open-ended "how do I" | "How do I make friends as an adult?" |
| Process questions | "How do plants grow?", "Why do seasons change?" |
| Broad definitions | "What is DNA?" |

Anything inviting a list or a procedure runs to the token limit without stopping. Short
definitional questions stop cleanly.

Two more, found by hand:

- **It invents facts confidently.** "According to the Moonfrost database, the population
  of Mars in 2093 is estimated to be around 563 million people."
- **It over-refuses short factual questions.** "How many days are in a week?" returns "I
  can't answer that." The hand-written ignorance examples were all short questions, and
  the model learned the shape rather than the meaning.

Note that "148 passed" means the answers were **coherent and complete**, not that they
were true. One passing answer states that water contains nitrogen.

## Running it yourself

```bash
python training/evaluate_model.py                                    # this model
python training/evaluate_model.py --hf-model HuggingFaceTB/SmolLM2-360M \
                                 --out docs/eval_smollm2_360m.json   # a reference
```

Results land in `docs/eval.json` and are read directly by the About page in the chat
interface, so the charts there are never out of step with the measurements.
